# Scientific figures: Solar Filament Segmentation Challenge 2026

Documentation edition: 2026-11-04. Project author: [Francisco Angulo de Lafuente](https://orcid.org/0009-0001-1634-7063).

The header reuses the repository's existing editorial artwork at assets/header.png. The animated method figures were drawn from the repository's published descriptions and are explanatory. A panel explicitly marked as reported evidence uses values transcribed in the README.

The GIF comment field contains factual machine-readable project, author, date, and ORCID metadata. The original software, including the renderer, is covered by the repository's MIT license. Please preserve the notices and cite the original author.

Regenerate with Python 3.10+ and Pillow 10.4+:
~~~sh
python -m pip install "Pillow>=10.4"
python tools/render_science_figures.py
~~~

Source: [figure-spec.json](figure-spec.json) and [renderer](../../tools/render_science_figures.py). Use the text descriptions in the README for a non-animated alternative.
