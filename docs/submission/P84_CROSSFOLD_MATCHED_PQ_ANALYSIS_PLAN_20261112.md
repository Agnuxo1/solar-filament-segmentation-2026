# P84  Post-hoc matched-step native-PQ integrity and uncertainty audit

Recorded 12 November 2026 UTC after F1F4 results were viewed and after P83 had completed. This plan is **post-hoc**; it is not a prospectively registered efficacy study and does not create an untouched test set. The objective is to measure the 7,200-step treatment-versus-control effect within each previously executed replicate using identical physical-image bootstrap draws, and establish whether further expensive GPU training is warranted. This also checks that the stored native PQ values can be exactly reconstructed from image-level count tuples.

Frozen inputs: P59 original F1 held-out report, all three P83 independent F1 held-out reports, and both seeds of every F2F4 held-out report. All holdouts derive exclusively from Kaggle TRAIN labels; no competition TEST ground truth, public-leaderboard tuning, or new training is permitted. Explicit physical-image sample sizes are F1=139, F2=146, F3=139, F4=143. Four model arms per report must be present. Models, thresholds, checkpoints, image partitions and any pre-existing selections remain unchanged.

Primary descriptive endpoint: matched-step delta = PQ(7200 treatment) minus PQ(7200 control), with deterministic, 4096-replicate nonparametric physical-image paired bootstrap intervals per run. Validate each report's native PQ against its stored physical-image counting and freeze policy per fold; reject invalid/missing values. Secondary outcome: cross-run sign distribution, not a pooled significance test: seeds sharing images and temporal folds are dependent. Confidence intervals only reflect within-run sampled-image variation, not between-seed or cross-fold uncertainty. No claims that training caused an improvement solely from these exploratory intervals.

Decision rule: preserve H9b and do not submit a new candidate to Kaggle; any subsequent GPU experiment must be separately motivated, reviewed and preregistered with an independent validation plan. Compute cost: CPU-only, <=2 cores, <1 GiB RAM, <20 MiB HDD, <=120 seconds, no write to /mnt/datos, no GPU1 activity. Test synthetic score integrity and deterministic bootstrap before processing reports. Keep every negative result and raw SHA-256 provenance.
