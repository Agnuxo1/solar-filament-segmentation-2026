Independent compressed-COCO area and intersection operations agreed with interval-based calculations. Every changed-mask pixel XOR was checked after decoding. All frozen P107 control totals were reproduced exactly.

**Falsification:** bounding boxes were not always identical (15 cases), and one mask changed from one 8-connected foreground component in accepted H9b to two components in the P106 clean replay. This was image `20130110085614Th`, matched instance `_5`, with five symmetric-difference pixels and an area increase of one pixel. The remaining 132 changed pairs retained their connected-component counts; that is a statement about geometric stability, **not** prediction accuracy. The fact that the median difference is one pixel does not justify claiming full topology invariance.

## Decision and safety

This audit used only two frozen **prediction** CSVs. It did not read TRAIN or test labels, compute Panoptic Quality, infer new scores, train models, call Kaggle or alter the organizer form. GPU0 and GPU1 processes were not touched; the user service was CPU-only with a 100% CPU quota, 4 GiB memory limit and 900-second runtime ceiling. The original accepted H9b CSV, Kaggle final selection 58112557 (public PQ 0.39) and official final submission receipts remain unchanged.

**Promotion is disabled.** No variant generated by P109 should be uploaded. The evidence refines the reproducibility statement: the clean public pipeline is extremely close to, but not exactly equivalent to, the selected H9b output, including rare box and component differences. No JEV/Goldfish consultation is asserted.
