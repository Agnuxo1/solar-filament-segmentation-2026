## Scientific motivation and hypothesis
P107 and P109 used per-image Hungarian matching to compare public replay P106 against accepted H9b. P109 found 1,108 exact pairs and 133 changed pairs (270 symmetrically different pixels). The additional question is whether these counts depend on equally optimal instance assignments. The **falsifiable hypothesis** is that every nontrivial image (two or more instances) has a uniquely optimal assignment at score margin strictly greater than 1e-12, using sum of COCO IoU as the objective. A tied optimum would invalidate an unconditional claim of assignment uniqueness; near ties below 1e-8 are reported separately.

## Frozen procedure
For each image, sort instance IDs, calculate all pairwise IoUs using `pycocotools.mask.iou`; obtain maximum-sum one-to-one match with SciPy Hungarian. For every selected pair, forbid that one edge and solve again, giving an independent runner-up constrained to differ from the optimum; take the maximum alternative. Record best-minus-runner-up margin. Single-instance images have structurally unique assignments and no numeric alternative. Recompute the match using reversed matrix and compare the optimum. Synthetic tests must prove positive margin for unique 2x2 and zero margin for tied 2x2. Report all images with margin <=1e-12 and <=1e-8, plus minimum positive margin and per-image results. **No tuning or candidate promotion**.
